# 中国象棋 · 极简对弈

一个不依赖后端的单文件中国象棋网页：本地双人、三档 AI、好友房间联机，以及剪刀石头布选边。

## 功能

- **自我对战**：同一屏幕红绿双方轮流落子。
- **AI 对决**：简单 / 中等 / 困难三档棋力，自选执红或执绿，棋盘自动转向玩家一侧。AI 运行在独立 Worker 中，不阻塞棋盘界面。
- **自定义房间**：创建 6 位房间号，好友输入房间号加入；双方各自选择阵营，房主开始对局。
- **选边对决**：双方选择同一阵营时自动进入剪刀石头布，率先赢下 2 回合的一方取得所选阵营，另一方自动执另一阵营。平局重赛。
- **落子音效**：使用 Web Audio 合成木质落子声，可随时开关，偏好保存在本地。
- **悔棋与重开**：本地和 AI 对局支持悔棋；联机对局由房主重新开始。
- 完整基础规则：马腿、象眼、炮架、九宫、过河兵、将帅照面、将军、将死与困毙。

## 使用与构建

直接用浏览器打开 `index.html` 即可。线上房间功能需要联网（PeerJS 公共信令服务）。

修改源码后重新生成单文件：

```bash
node build.js
```

- `src/index.html`：页面样式与结构模板。
- `src/app.js`：规则引擎、AI、界面、联机逻辑。
- `vendor/peerjs.min.js`：PeerJS 1.5.5，MIT License。
- `index.html`：构建产物，也是 GitHub Pages 入口。

## 联机说明

联机使用 WebRTC 点对点直连，PeerJS 公共云服务只负责建立连接，棋局数据不经过业务后端。双方需要同时在线；刷新页面或断开连接后房间会关闭。严格的 NAT / 防火墙环境可能无法建立直连。

联机悔棋暂未开放，避免双方棋盘状态不一致；房主可重新开始整局。

## 规则边界

当前实现采用常见的简化胜负规则：将死、困毙判负，不实现长将、长捉和重复局面判和。联机落子由房主校验并广播，带对局编号防止重开局后旧消息串局。
