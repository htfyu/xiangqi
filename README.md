# 中国象棋 · 极简对弈

在线试玩：**https://htfyu.github.io/xiangqi/**

一个不依赖后端的单文件中国象棋网页：本地双人、三档 AI、好友房间联机，以及剪刀石头布选边。

## 功能

- **自我对战**：同一屏幕红绿双方轮流落子。
- **AI 对决**：简单 / 中等 / 困难三档棋力，自选执红或执绿，棋盘自动转向玩家一侧。AI 运行在独立 Worker 中，不阻塞棋盘界面。
- **自定义房间**：创建 6 位房间号，好友输入房间号加入；双方各自选择阵营，房主开始对局。
- **选边对决**：双方选择同一阵营时自动进入剪刀石头布，率先赢下 2 回合的一方取得所选阵营，另一方自动执另一阵营。平局重赛。
- **认输**：按下认输的一方确认后立即判负；联机时由认输方的对手获胜。
- **和棋**：向对手发起和棋请求，对手弹窗选择「√ 接受和棋」或「× 继续对弈」；AI 对局会评估局势后回应。
- **五种落子音效**：木击、石击、水滴、机械轴、爆炸，可试听、切换、调节音量或静音，偏好保存在本地。
- **悔棋与重开**：本地和 AI 对局支持悔棋；联机对局由房主重新开始。
- 完整基础规则：马腿、象眼、炮架、九宫、过河兵、将帅照面、将军、将死与困毙。被将军时可用任意合法棋子解将，支持弃子挡将或吃子；只会禁止让帅/将处于被将军状态的走法。
- 走子反馈：点击无效落点时保留当前选中棋子，并在棋盘顶部状态栏提示原因（不能到达、仍无法解将、会送将等），不再为每次点击弹出底部浮层。被将军时，可用解将的其他棋子会显示虚线环，明确告知可以选择弃子。
- 联机可靠性：开局确认与自动重试、断线清理、前台恢复自动同步棋盘、协议版本检查。

## 使用与构建

直接用浏览器打开 `index.html` 即可。线上房间功能需要联网（PeerJS 公共信令服务）。

修改源码后重新生成单文件：

```bash
node build.js
```

- `src/index.html`：页面样式与结构模板。
- `src/app.js`：规则引擎、AI、界面、联机逻辑。
- `vendor/peerjs.min.js`：PeerJS 1.5.5，MIT License。
- `index.html`：构建产物，也是 GitHub Pages 入口。

## 联机说明

联机使用 WebRTC 点对点直连，PeerJS 公共云服务负责信令，棋局数据不经过业务后端。双方需要同时在线；刷新页面或断开连接后房间会关闭。严格的 NAT / 防火墙环境可能无法建立直连。

手机与电脑联机时请保持双方页面在前台。游戏开始会进行开局确认与自动重试；手机页面从后台回到前台时会自动同步棋盘。若提示页面版本不一致，请双方刷新后重新建房。

联机悔棋暂未开放，避免双方棋盘状态不一致；房主可重新开始整局。联机认输和和棋会实时同步。

## 规则边界

当前实现采用常见的简化胜负规则：将死、困毙判负，认输判负，双方同意和棋则平局；不实现长将、长捉和重复局面判和。联机落子由房主校验并广播，带对局编号防止重开局后旧消息串局。
